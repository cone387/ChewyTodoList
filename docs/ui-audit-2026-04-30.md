### P0-1 · 深色模式基本失效（全局）

**现象**：设置页有深色模式开关，但切换后 90% 以上界面不变色。

**根因**：
- [mobile/constants/theme.ts:88](mobile/constants/theme.ts:88) — `export const Colors = LightColors;` 这是一个**静态常量**
- 全 repo 扫描：**36 个 .tsx 文件 import `Colors`**（永远是 Light），只有 **3 个文件使用 `useTheme()`**
- 34 个文件直接写 `backgroundColor: '#fff'` / `'#f9fafb'` / `'#111418'` 等硬编码色值
- 结果：根布局响应了 `isDark`，但几乎所有子组件依然是白底黑字

**修复方向**：
1. 移除 [mobile/constants/theme.ts:88](mobile/constants/theme.ts:88) 的 `Colors` 静态导出（或标记 deprecated）
2. 所有页面改用 `const { colors } = useTheme()`，写 `colors.background.primary` 而不是 `'#fff'`
3. 提一个 codemod task（可单独 spec）：扫描所有 `'#fff'`/`'#111418'`/`'#9ca3af'` 等硬编码色，替换为 theme tokens

**影响面**：整个 mobile app。**工作量**：2 d。
